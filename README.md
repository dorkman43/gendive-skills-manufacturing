# gendive-skills-manufacturing (제조 데이터 활용 스킬)

생산·자재 담당자가 엑셀 자료로 **불량 분석과 발주 시점 판단**을 할 수 있게 돕는 한국어 스킬 모음입니다. 비개발자도 쓸 수 있게 쉬운 말로 작성했고, OEE·직행률처럼 회사마다 정의가 다른 지표는 사용자에게 먼저 확인하도록 했습니다.

## 스킬 목록

| 폴더명 | 한국어 이름 | 하는 일 | 이렇게 말하면 작동 |
|---|---|---|---|
| `production-defect-analysis` | 생산실적·불량 분석 | 불량률·달성률·직행률·OEE를 계산하고 파레토, 교대·라인·자재 로트별 패턴, 평소와 다른 날, 원인 후보(확인됨/가설)를 정리 | "불량이 왜 늘었는지 봐줘", "라인별 교대별 불량률 비교해줘" |
| `reorder-timing` | 재고·계절성 발주 시점 판단 | 이미 늦음/지금 발주/곧 발주/정상 4단계로 판정하고 발주 초안과 장기 체화 재고 목록을 만듦 | "언제 발주해야 해?", "곧 떨어지는 재고 뽑아줘" |

## 쓰는 법 3가지

1. **Claude (무료 포함)**: 설정 → 기능에서 "코드 실행 및 파일 생성"을 켜고, `skills/<스킬이름>` 폴더를 zip으로 묶어 설정 → 스킬에서 업로드합니다.
2. **Claude Code / Cowork**: `/plugin marketplace add dorkman43/gendive-skills-manufacturing` 를 입력한 뒤 플러그인을 설치합니다.
3. **ChatGPT·Gemini**: `SKILL.md` 의 머리말(`---` 사이)을 뺀 본문을 프로젝트 지침(ChatGPT) 또는 대화 첫 메시지에 붙여 넣고 파일을 올립니다.

## 함께 쓰면 좋은 저장소

- **gendive-skills-common**: 작업자 이름·거래처 정보가 있으면 올리기 전에 `data-masking`으로 먼저 가리세요. 엑셀 정리는 `excel-cleanup`, 그래프는 `chart-dashboard`, 보고서 점검은 `report-qa`가 도움이 됩니다.

## 실습 데이터

`samples/` 폴더에 가상 데이터가 있습니다(생산실적, 재고_출고이력). 일부러 넣은 함정(특정 라인 야간조 불량 증가, 불량 자재 로트, 재고 0 기간, 신규·장기 미출고 품목 등)과 **검산용 정답**은 `samples/README.md`에 있습니다. 다시 만들려면 저장소 폴더의 터미널(명령 입력창)에서 `python3 samples/make_samples.py` 를 실행합니다. 모든 회사·숫자는 가상입니다.

## 주의

**실제 회사 데이터(생산실적, 재고, 거래처 정보)를 무료·개인용 AI 계정에 올리지 마세요.** 회사가 승인한 도구인지, 입력 내용이 학습에 쓰이지 않는 계약인지 확인한 뒤 사용하세요. 지표 정의(OEE, 직행률 등)는 일반적으로 쓰는 정의이며 회사 정의가 있으면 그것이 우선입니다. 스킬은 발주나 설비 조치를 대신하지 않고 초안까지만 만듭니다.
