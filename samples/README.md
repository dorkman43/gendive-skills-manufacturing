## 1. 생산실적.xlsx (production-defect-analysis)

- 불량유형은 줄마다 "주된 유형" 하나만 적혀 있어 파레토는 이 기준입니다. 정의: 생산수량 = 양품수량 + 불량수량, 양품수량은 재작업 후 합격분 포함, 재작업수량은 그중 재작업을 거친 수.
- **일부러 넣은 지저분함**: 일자 5줄은 문자열("2026.03.04"), 라인 표기 8줄이 "1라인"처럼 다름, 비가동사유 빈칸 6줄(비가동시간은 있음), 재작업수량 빈칸 3줄(0이 아님).
- **심어 둔 패턴 3가지**
  1. 2호라인 **야간조**, 2026-06-01~07-15에 **치수불량**이 늚 (설비 쪽 가설 - 원인은 데이터로 확정 불가, 확인 필요).

## 2. 재고_출고이력.xlsx (reorder-timing)

- `일별출고` 시트 550행(품목 18열, 2024-07-01~2026-09-30, 영업일만), `품목정보`(리드타임·최소발주량·발주단위·단가), `현재고`, `입고예정`, `재고0기간` 시트. 기준일은 2026-09-30.
- **심어 둔 함정**: ① 계절성 품목 R-008(여름 성수기)·R-009(겨울 성수기) ② 재고 0 기간(R-005 2025-11-10~14, R-012 2026-09-15~18 - 이 날의 출고 0은 수요 0이 아니므로 평균에서 제외, 최근 4주 안에 걸린 R-012가 핵심) ③ 이력이 짧은 신규 R-017(2026-09-01 시작, 그 전은 빈칸), 이력 1년 미만 R-016 ④ 90일 이상 출고 없는 R-014·R-018 ⑤ 1주 평균은 추석 연휴 주(9/24·25 휴무)라 낮게 나옴 ⑥ R-006은 현재고만 보면 부족하지만 입고예정을 더하면 충분함.

**검산용 정답 - 스킬 본문의 공식 그대로** (기준일 2026-09-30)
- 일평균(4주) = 최근 28일 출고합 / (28일 - 재고0 일수) (달력일 기준, 휴무일은 출고 0으로 포함). 1주는 최근 7일.
- 주간 변동 = 최근 12주 각 주(7일) 출고량의 표준편차(재고0이 낀 주 제외). 안전재고 = 1.65 x 주간 변동 x √(리드타임/7) (서비스수준 95%, 정규분포 가정).
- 계절성 보정(이력 1년 이상일 때만) = 전년 (기준일+리드타임)이 속한 달의 영업일 평균 / 전년 기준일이 속한 달의 영업일 평균. 보정 일평균 = 4주 일평균 x 보정.
- 발주점 = 보정 일평균 x 리드타임 + 안전재고, 가용재고 = 현재고 + 입고예정, 재고일수 = 가용재고 / 보정 일평균.
- 판정: 재고일수 < 리드타임 -> 이미 늦음 / 가용재고 <= 발주점 -> 지금 발주 / (가용 - 발주점) / 일평균 <= 14일 -> 곧 발주 / 그 외 정상. 발주량 = max(최소발주량, 발주점 + 30일치 - 가용재고)를 발주단위로 올림.
